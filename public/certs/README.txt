Place your certificate PDF files in this folder.

Recommended filenames:
- iPetro_Certificate.pdf
- Google_Cloud_Certificate.pdf

After adding the files, they will be available at these URLs in development:
- http://127.0.0.1:5175/certs/iPetro_Certificate.pdf
- http://127.0.0.1:5175/certs/Google_Cloud_Certificate.pdf

(Use the URL shown by Vite's dev server if a different port is used.)
